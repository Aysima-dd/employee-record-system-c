# employee-record-system-c
A simple employee record system developed using the C programming language.

## About the project
This program allows users to store and display basic employee information:

- First name
- Last name
- Age
- Monthly salary

## Features
- Add a new employee
- Display all registered employees
- Store up to 100 employees
- Exit the program

## How to Use
When the program starts, the user can choose one of three options:

1- Add employee information
2- Display employee records
3- Exit

## Purpose
The purpose of this project is to practice using struct, arrays, functions, and basic control structures in the C programming language.
